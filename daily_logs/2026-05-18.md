## 23:49 — Consultation: alternative scorer for Model Explorer (σ-envelope coverage vs χ² vs Anderson–Darling)

**Topics:** Bias correction validation, Model Explorer scoring, logL interpretation, CDF goodness-of-fit, chi-squared, Anderson–Darling, Kolmogorov–Smirnov, coverage diagnostics

**Work done:**
- Discussed a proposed second scorer for the Model Explorer (Bias Correction validation tab) that grades how well the data CDF sits within the ±1σ / ±2σ / ±3σ envelope of the 5000-iteration simulated ΔRV CDF
- Showed that the user's intuition (reward inside 1σ, penalise beyond 3–4σ) is mathematically equivalent to χ² with 1/σ² weighting, and that under Gaussian per-bin assumptions logL = −½χ² + const — so the current logL already does this in spirit
- Flagged the key subtlety: CDF bins are correlated (monotonic ⇒ a miss is re-counted at every larger ΔRV), so naive χ²-on-CDF overcounts evidence
- Surveyed CDF-aware statistics: KS, Cramér–von Mises, Anderson–Darling. Recommended **AD** because its 1/[F(1−F)] weighting upweights tails, matching the physical informativeness of high-ΔRV binaries
- Argued *against* harder-than-quadratic tail penalties; defensible direction for WR data is softer (Student-t / Huber) so one extreme binary doesn't dominate
- Offered three concrete next steps: (a) audit current per-bin likelihood, (b) sketch AD-based scorer, (c) prototype a coverage diagnostic (% of data CDF inside ±1σ/2σ/3σ) next to logL — user has not chosen yet

**Decisions:**
- No code written this session — consultation only. User wants to think it over.
- Anderson–Darling identified as the natural CDF-aware analog of the user's sigma-weighted intuition; coverage diagnostic identified as the cheapest and most interpretable add-on (logL has no natural "good fit" scale).
