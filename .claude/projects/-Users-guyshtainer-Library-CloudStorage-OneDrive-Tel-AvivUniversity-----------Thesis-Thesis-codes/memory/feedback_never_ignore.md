NEVER ignore or skip part of a user request. When the user asks for two things (e.g., "do X and same for Y"), do BOTH fully.

**Why:** User explicitly called out being ignored when they asked for features to be cataloged for both bias correction AND plots pages, but only bias correction was addressed. This is a serious trust violation.

**How to apply:** Before responding, re-read the user's message and verify EVERY request in it is addressed. If there are multiple items, check each one off mentally before submitting.
